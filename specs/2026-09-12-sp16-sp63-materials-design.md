## Нормативная база и границы ответственности

Указанные HTML-файлы являются единственным нормативным источником численных таблиц
для этой задачи. Локальные markdown-выгрузки норм проверены как вспомогательный
материал, но не смешиваются с выбранным профилем: в них встречаются другая редакция,
потерянные знаменатели и расхождения в приложении В СП 16. Поддержка более новой
редакции оформляется отдельным нормативным профилем, а не неявным объединением таблиц.
GreenSectionPy используется для сверки формул и узлов диаграмм, OpenCS — для сверки
знаковой конвенции, вариантов диаграмм и поведения при интеграции. Внешние проекты не
будут становиться runtime-зависимостями локального селектора.

Модуль выбирает нормативные характеристики и строит диаграммы. Выбор коэффициентов
условий работы из реальной расчётной ситуации (геометрия, нагрузка, класс элемента)
остаётся ответственностью вызывающего кода; селектор должен показывать допустимые
нормативные варианты и не подменять их произвольными значениями.

### Коэффициенты условий работы

- `gamma_b1` определяется длительностью нагрузки только если не задан явно; для
  ячеистого и поризованного бетона учитывается нормативное значение для этого
  типа, включая предусмотренное СП значение 0.85.
- `gamma_b2` применяется только в предусмотренном СП случае бетонной конструкции;
  режим бетонной/железобетонной конструкции должен быть явным либо переопределяться
  явным коэффициентом.
- `gamma_b3` действует на сжатие, но не на растяжение.
- `gamma_b4` трактуется по СП 63 как коэффициент для ячеистого бетона и влажности,
  а не как произвольный коэффициент замораживания. Влажность для таблиц деформаций
  и влажность ячеистого бетона для `gamma_b4` — разные именованные входы.
- `gamma_b5` — явный внешний коэффициент условий работы для влияния попеременного
  замораживания и оттаивания по 6.1.12 и 6.1.27. По умолчанию он равен 1.0,
  проверяется условие `0 < gamma_b5 <= 1.0`, не выводится автоматически из типа
  бетона и не должен молча игнорироваться. При отличии от 1.0 он применяется к
  соответствующим характеристикам прочности и деформационным характеристикам
  по нормативному контексту, включая 6.1.27.

### Диаграммы бетона

Сохранить существующий режим выдачи одной ветви в положительных величинах для
совместимости, но добавить явную знаковую конвенцию (`signed=True` или эквивалентный
параметр). В signed-режиме сжатие имеет `epsilon < 0, sigma < 0`, растяжение —
`epsilon > 0, sigma > 0`, как в OpenCS и GreenSectionPy.

- Проверить `state` и `model`, а также положительное значение `n_points`.
- Двухлинейная диаграмма строится по 6.1.21 через явно заданную нормативную
  деформацию перехода `epsilon_b1,red`, а не через `epsilon_b0` и не через
  вычисленное отношение `Rb / Eb,red`. Для кратковременной нагрузки принимаются
  нормативные значения 0.0015 для тяжёлого бетона и 0.0022 для лёгкого бетона;
  для длительной нагрузки используются значения соответствующей третьей колонки
  таблицы 6.10. В растянутой ветви аналогично хранится отдельная
  `epsilon_bt1,red` (кратковременное значение 0.00008, длительные значения — из
  таблицы 6.10). Формула 6.9 `Eb,red = Rb / epsilon_b1,red` не смешивается с
  временным модулем `Eb,tau = Eb / (1 + phi)`.
- Трёхлинейная диаграмма строится по 6.1.20 через точки `0`, `0.6 R`, `R` и
  нормативные предельные деформации; искусственный коэффициент `0.85` удаляется.
- Криволинейная диаграмма строится по формулам приложения Г (Г.2–Г.9), а не по
  рациональной аппроксимации текущей реализации. Для сжатия используются
  `sigma_hat_b = -Rb,ser`, для растяжения — `sigma_hat_bt = Rbt,ser`, то есть
  нормативные сопротивления для предельных состояний II группы. Параметры
  `nu_0`, `omega_1`, `epsilon_hat_b`, `nu_hat_bt=0.5`, `epsilon_hat_bt=1` и
  остальные параметры Г.2–Г.8 вычисляются явно; неявные формулы решаются
  численно устойчивым методом. Нисходящая ветвь сжатия используется только до
  уровня `eta >= 0.85`, а не продолжается произвольно до конца массива.
- Диапазон и узловые точки не должны обрезать нисходящую ветвь или скрывать пик.
  При дискретизации конечные точки, пик и граница `eta=0.85` должны присутствовать
  в результирующих массивах.

4. Формулы коэффициентов и болтовых несущих способностей.
5. Узловые значения, знаки, монотонность и конечные точки диаграмм СП 63 и СП 16.
6. Выбор двух-/трёхлинейной модели арматуры и вариантов В.1.
7. Синтаксическая проверка генераторов, выполнение обоих блокнотов и проверка их
   графических выходов.

После реализации выполняются весь локальный набор `pytest`, выполнение блокнотов и
визуальный осмотр сохранённых графиков/HTML. В отчёте явно отделяются исправленные
ошибки от ограничений, которые СП требует задавать внешним расчётным контекстом.
