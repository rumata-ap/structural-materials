СП 16.13330.2017 «Стальные конструкции»
=========================================

Модуль ``structural_materials.sp16_materials`` реализует нормативные расчетные характеристики прокатной стали и болтовых соединений по СП 16.13330.2017 (с Изменениями № 1, 2, 3).

Прокатная сталь (класс ``StructuralSteel``)
-------------------------------------------

Класс :class:`~structural_materials.sp16_materials.StructuralSteel` определяет:

* **Расчетные сопротивления растяжению, сжатию, изгибу по пределу текучести**: :math:`R_y` (Таблицы В.3, В.4, В.5).
* **Расчетные сопротивления по временному сопротивлению**: :math:`R_u`.
* **Расчетные сопротивления сдвигу**: :math:`R_s = 0{,}58 R_y`.
* **Расчетные сопротивления смятию торцевой поверхности**: :math:`R_p` (Таблица В.6).
* **Расчетные сопротивления смятию в шарнирах**: :math:`R_{lp} = 0{,}5 R_y`.
* **Расчетные сопротивления смятию катков**: :math:`R_{cd}`.
* **Модуль упругости**: :math:`E = 2{,}06 \times 10^5` МПа (п. 5.3).
* **Коэффициенты надежности по материалу**: :math:`\gamma_m = 1{,}025` (со статистическим контролем качества) или :math:`\gamma_m = 1{,}050` (без него).
* **Каталог коэффициентов условий работы**: :math:`\gamma_c` (Таблица 1).

Поддерживаемый сортамент и марки стали:
* **Фасонный прокат (Таблица В.5)**: С235, С245, С255, С345, С355, С390, С440, С590 по ГОСТ 27772 (толщина принимается по полке :math:`t_f`).
* **Двутавры по ГОСТ Р 57837 (Таблица В.4)**: С255Б, С345Б, С355Б, С390Б, С440Б (толщины до 160 мм).
* **Листовой и широкополосный прокат (Таблица В.3)**.

Пример использования:

.. code-block:: python

   from structural_materials import StructuralSteel

   # Фасонный прокат С255, толщина полки tf = 14 мм, со статистическим контролем
   steel = StructuralSteel(
       grade='С255',
       profile_type='shapes',
       thickness=14.0,
       statistical_control=True,
       gamma_c=1.0
   )

   print(f"Ry = {steel.Ry} МПа")
   print(f"Ru = {steel.Ru} МПа")
   print(f"Rs = {steel.Rs:.1f} МПа")
   print(f"Rp = {steel.Rp} МПа")

Болтовые соединения (класс ``SteelBolt``)
-----------------------------------------

Класс :class:`~structural_materials.sp16_materials.SteelBolt` выполняет расчет характеристик болтов нормальной и повышенной прочности:

* Классы прочности: ``5.6``, ``5.8``, ``8.8``, ``10.9``, ``12.9`` (Таблица Г.3).
* Номинальные диаметры: от ``М16`` до ``М48`` (Таблица Г.5, Г.9).
* Площадь сечения брутто :math:`A` и площадь сечения нетто по резьбе :math:`A_{bn}` (Таблица Г.9).
* Расчетные сопротивления срезу :math:`R_{bs}` и растяжению :math:`R_{bt}` (Таблица Г.5).
* Несущая способность на срез :math:`N_{bs} = R_{bs} \gamma_b n_s A` и на растяжение :math:`N_{bt} = R_{bt} A_{bn}` (п. 14.2.5).

Пример использования:

.. code-block:: python

   from structural_materials import SteelBolt

   bolt = SteelBolt(grade='8.8', diameter=20, gamma_b=0.9)

   print(f"Rbs = {bolt.Rbs} МПа")
   print(f"Rbt = {bolt.Rbt} МПа")
   print(f"Несущая способность на срез (1 плоскость трения): Nbs = {bolt.shear_capacity(n_s=1):.1f} кН")
   print(f"Несущая способность на растяжение: Nbt = {bolt.tension_capacity():.1f} кН")

Деформационные диаграммы стали
------------------------------

Поддерживаются расчетные диаграммы вариантов по Приложению Б:
* **Вариант OBD** (диаграмма Прандтля с площадкой текучести).
* **Вариант OACD** (трехлинейная диаграмма).
* **Вариант OACDEF** (диаграмма с упрочнением и ниспадающей ветвью).
