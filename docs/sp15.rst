СП 15.13330.2020 «Каменные и армокаменные конструкции»
=========================================================

Модуль ``structural_materials.sp15_materials`` реализует полные каталоги нормативных характеристик каменной кладки по СП 15.13330.2020 (Таблицы 6.1–6.18), а также расчет сетчатого армирования.

Неармированная кладка (класс ``Masonry``)
-----------------------------------------

Класс :class:`~structural_materials.sp15_materials.Masonry` рассчитывает:

* **Расчетные сопротивления сжатию**: :math:`R` (Таблицы 6.1–6.7) с учетом сносок:
  - Тип раствора (цементный с известью/глиной, тяжелый, легкий цементный).
  - Подготовка образцов (сухое/водонасыщенное состояние).
  - Пустотность камней и кирпича.
  - Возраст раствора при твердении.
  - Наличие пазогребневого соединения и клеевых составов.
* **Расчетные сопротивления растяжению и срезу**: :math:`R_t, R_{tb}, R_{sq}` по неперевязанным и перевязанным сечениям (Таблицы 6.8–6.11).
* **Упругие характеристики кладки**:
  - Начальный модуль упругости: :math:`E_0 = \alpha R_u` (Таблица 6.12, 6.13).
  - Модуль деформаций при расчете прочности: :math:`E_{strength}`.
  - Модуль деформаций при определении усилий и деформаций: :math:`E_{stiffness}`.
* **Временное сопротивление (предел прочности) сжатию**: :math:`R_u = k R`.

Пример использования:

.. code-block:: python

   from structural_materials import Masonry

   # Кладка из полнотелого кирпича М150 на цементном растворе М100
   masonry = Masonry('brick', 'M150', 'M100')

   print(f"R = {masonry.R:.2f} МПа")
   print(f"Ru = {masonry.Ru:.2f} МПа")
   print(f"E0 = {masonry.E0:.0f} МПа")
   print(f"E (деформации) = {masonry.E_stiffness:.0f} МПа")

Армокаменная кладка с сетчатым армированием (класс ``ReinforcedMasonry``)
--------------------------------------------------------------------------

Класс :class:`~structural_materials.sp15_materials.ReinforcedMasonry` рассчитывает несущую способность по формуле (7.23) СП 15.13330.2020:

.. math::

   R_{sk} = R + \frac{2 \mu R_s \gamma_{cs}}{100}

где:
* :math:`\mu = \frac{2 A_s}{c \cdot s}` — процент армирования по объему.
* :math:`\gamma_{cs}` — коэффициент условий работы сетчатой арматуры (Таблица 6.14).
* :math:`R_s` — расчетное сопротивление арматурной стали сеток.

Также выполняются нормативные проверки:
* Ограничение процента армирования :math:`0{,}1\% \le \mu \le 1{,}0\%` (п. 7.31).
* Проверка максимального сопротивления :math:`R_{sk} \le 2 R` (п. 7.23).
* Шаг сеток по высоте :math:`s \le 400` мм и :math:`s \le 5` рядов кладки (п. 9.81а).

Пример использования:

.. code-block:: python

   from structural_materials import Masonry

   masonry = Masonry('brick', 'M150', 'M100')

   # Армирование сеткой: d = 4 мм (В500), ячейка c = 50 мм, шаг по высоте s_vert = 65 мм
   reinforced = masonry.with_mesh_reinforcement(d=4, s=50, c=2, s_vert=65)

   print(f"Процент армирования μ = {reinforced.mu:.2f}%")
   print(f"Расчетное сопротивление Rsk = {reinforced.Rsk:.2f} МПа")
