СП 63.13330.2018 «Бетонные и железобетонные конструкции»
===========================================================

Модуль ``structural_materials.sp63_materials`` предоставляет классы и функции для вычисления нормативных и расчетных характеристик бетона и арматуры, а также построения деформационных диаграмм по СП 63.13330.2018 (с Изменениями № 1).

Бетон (класс ``Concrete``)
--------------------------

Класс :class:`~structural_materials.sp63_materials.Concrete` рассчитывает:

* **Нормативные сопротивления**: :math:`R_{bn}`, :math:`R_{btn}` (Таблица 6.7).
* **Расчетные сопротивления (I группа ПС)**: :math:`R_b`, :math:`R_{bt}` (Таблица 6.8).
* **Расчетные сопротивления (II группа ПС)**: :math:`R_{b,ser} = R_{bn}`, :math:`R_{bt,ser} = R_{btn}`.
* **Коэффициенты условий работы бетона**: :math:`\gamma_{b1}` (длительность нагрузки), :math:`\gamma_{b2}`, :math:`\gamma_{b3}`, :math:`\gamma_{b4}`, :math:`\gamma_{b5}` (Таблица 6.9).
* **Модули деформаций**: начальный :math:`E_b` (Таблица 6.11), приведенный с учетом ползучести :math:`E_{b,red}` (п. 6.1.15).
* **Коэффициент ползучести**: :math:`\varphi_{b,cr}` (Таблица 6.12).
* **Предельные деформации**: :math:`\varepsilon_{b0}, \varepsilon_{b2}, \varepsilon_{bt0}, \varepsilon_{bt2}` (Таблицы 6.10).

Поддерживаемые виды бетона:
* Тяжелый (``heavy``)
* Мелкозернистый (``fine_grained``) групп А, Б, В
* Легкий (``light``)
* Поризованный (``porous``)
* Ячеистый (``cellular``) автоклавный и неавтоклавный
* Напрягающий (``stressing``)

Пример использования:

.. code-block:: python

   from structural_materials import Concrete

   # Тяжелый бетон B25 при длительной нагрузке и влажности воздуха 40-75%
   concrete = Concrete('B25', concrete_type='heavy', humidity='40-75%', long_term=True)

   print(f"Rb = {concrete.Rb} МПа")
   print(f"Rbt = {concrete.Rbt} МПа")
   print(f"Eb = {concrete.Eb} МПа")
   print(f"Eb,red = {concrete.Eb_red:.1f} МПа")
   print(f"φb,cr = {concrete.phi_b_cr}")

Арматура (класс ``Rebar``)
--------------------------

Класс :class:`~structural_materials.sp63_materials.Rebar` рассчитывает:

* **Нормативные сопротивления**: :math:`R_{sn}` (Таблица 6.13).
* **Расчетные сопротивления растяжению**: :math:`R_s` (Таблица 6.14).
* **Расчетные сопротивления сжатию**: :math:`R_{sc}` (Таблица 6.14).
* **Расчетные сопротивления поперечной арматуры**: :math:`R_{sw}` (Таблица 6.15).
* **Модуль упругости**: :math:`E_s` (п. 6.2.12).
* **Предельные деформации**: :math:`\varepsilon_{s0}, \varepsilon_{s2}` (п. 6.2.14).

Поддерживаемые классы арматуры:
* Горячекатаная: ``A240``, ``A400``, ``A500``, ``A600``, ``A800``, ``A1000``.
* Холоднодеформированная: ``B500``.
* Канаты: ``K1400``, ``K1500``.

Пример использования:

.. code-block:: python

   from structural_materials import Rebar

   rebar = Rebar('A500')
   print(f"Rs = {rebar.Rs} МПа")
   print(f"Rsc = {rebar.Rsc} МПа")
   print(f"Rsw = {rebar.Rsw} МПа")
   print(f"Es = {rebar.Es} МПа")

Деформационные диаграммы бетона
-------------------------------

Модуль поддерживает построение всех трех нормативных диаграмм деформирования бетона по СП 63.13330.2018:

1. **Двухлинейная диаграмма** (п. 6.1.21).
2. **Трехлинейная диаграмма** (п. 6.1.20).
3. **Нелинейная диаграмма** (Приложение Г).

.. code-block:: python

   # Получение точек диаграммы
   eps, sig = concrete.get_diagram_points(diagram_type='curved', sign='compression')
